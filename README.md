# OpenThai use cases

Public submissions for the **"Who uses OpenThai"** page at <https://openthai.ai/usecases>.

If your organisation, product, research project or open-source project runs an OpenThai
or OpenThaiGPT model (any generation: OpenThaiGPT 1.0 / 1.5 / 1.6 / R1, OpenThai 2.0,
OpenThai 2.0 Legal, Chinda), we would love to list you.

**Submit:** fill in the form at <https://openthai.ai/usecases#submit>, or
[open a "Use case" issue](https://github.com/OpenThaiGPT/usecases/issues/new?template=usecase.yml)
directly. You can also email <kobkrit@aieat.or.th> or post in our
[Discord](https://discord.gg/7KDdKkBGUs).

Each accepted submission is added to the site's use-case catalogue with a link back to you.
We only list deployments that the submitter is entitled to describe publicly.
